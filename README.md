# 個人ホームページ

自分のホームページを作成するためのリポジトリです。
設計や実装を自分で考え、コードを書きながら制作を進めます。

## 開発方針

- コードの実装・修正は、基本的に自分で行います。
- 技術構成やページの内容は、制作を進めながら決めていきます。
- 決定した内容や開発手順は、必要に応じてこのREADMEに追記します。

## Codexの利用方針

Codexは、実装の相談やコードの書き方について助言を得るために利用します。

- 設計や実装方法の相談
- 文法やコードの書き方の解説
- 技術の選択肢や、それぞれのメリット・デメリットの整理
- 自分で書いたコードのレビューや改善案の提示
- エラーの原因調査や解決方法のアドバイス

Codexには実装を任せず、アプリケーションのコードや設定ファイルの作成・変更は依頼しない方針です。
相談への回答は説明やコード例の提示にとどめ、実際のファイルへの反映は自分で行います。
